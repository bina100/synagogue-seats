## הבעיה

ימות המשיח דורשים פורמט נוקשה: **כל תגובה חייבת להתחיל ב-`id_list_message=`** (גם אם ריק), אחרת המערכת זורקת "השלוחה אינה ניתנת להפעלה". בנוסף, פרמטר ה"ביפ" עם `yes` עלול לקרוס בקווים מסוימים.

זה תואם בדיוק למה ש-Gemini זיהה ולמה שראית בבדיקת הדפדפן (התגובה התחילה ב-`read=t-...`).

## התיקון

קובץ אחד: `supabase/functions/yemot-ivr/index.ts`

### שינוי 1 — פונקציית `readDigit` (שורה 71-76)
**לפני:**
```ts
return `read=t-${safe},ApiExtension,yes,1,1,7`;
```
**אחרי:**
```ts
return `id_list_message=&read=t-${safe},ApiExtension,no,1,1,7`;
```

מה השתנה:
- הוספת `id_list_message=&` בתחילת התגובה (ריק, רק כדי שהפורמט יתחיל כמו שימות מצפים).
- שינוי `yes` ל-`no` בפרמטר הביפ — בטוח יותר ולא דורש קובץ קול.

### שינוי 2 — פונקציית `speakAndHangup` (שורה 65-68)
היא כבר מתחילה ב-`id_list_message=t-...` ולכן תקינה. **לא משתנה.**
