
# עיצוב מחדש של דף היעדרויות

## סיכום השינויים

שכתוב מלא של `src/pages/AbsenceManager.tsx`:

### מה מוסר
- הקומפוננטה הפנימית `AbsenceSeatingMap` (שורות 477-727) - מוסרת לחלוטין
- תצוגת הטאבים (tabs) לבחירת מחלקה - מוסרת
- `selectedSectionId`, `activeSectionId`, `searchParams` - מוסרים
- בלוק ה-`print-only` הנפרד שמציג כל מחלקה בנפרד - מוסר

### מה מתווסף
- Query אחד שטוען את כל המחלקות עם שורות ומקומות (כמו ב-SeatingMap):
  ```
  sections -> seat_rows -> seats(*, profiles:assigned_to(id, full_name, username))
  ```
- תצוגת מפה מאוחדת - כל המחלקות זו לצד זו עם גלילה אופקית (בדיוק כמו SeatingMap)
- מקומות צבועים לפי סטטוס: טורקיז=שלי, אדום=תפוס, ירוק=פנוי/נעדר, אפור=לא שויך
- `print-color-adjust: exact` על כל מקום כדי שהצבעים יודפסו
- ה-Card העוטף את המפה מקבל class `print-floor-plan` (כמו SeatingMap)
- Mutations של גבאי (`markSeatAbsentMutation`, `cancelSeatAbsenceMutation`) מועברים ישירות לקומפוננטה הראשית
- דיאלוג פרטי מקום (גבאי) משולב ישירות בדף

### הדפסה
- כל הכרטיסים (שבת, חגים, פעולות גבאי, רשימת נעדרים, מקרא) מסומנים `no-print` ולא יופיעו בהדפסה
- הבאנר העליון (`print-header`) נשאר עם שם בית הכנסת ותאריך
- המפה מודפסת עם `zoom: 0.55` דרך ה-CSS הקיים של `print-floor-plan`

### מה נשאר כמו שהוא
- כרטיס שבת קרובה + כפתור "לא מגיע"
- חגים קרובים
- פעולות גבאי (סמן היעדרות למתפלל + הדפסה)
- רשימת נעדרים עם אפשרות ביטול
- כל ה-mutations הקיימים
